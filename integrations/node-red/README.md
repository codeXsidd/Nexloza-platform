# Node-RED Integration

Node-RED integration for the Nexloza IoT platform.

## Purpose

This directory will contain custom Node-RED nodes that interface with the Nexloza platform, enabling visual flow-based programming for IoT automations.

## Planned Features

- Nexloza MQTT input/output nodes
- Device command nodes
- Telemetry query nodes
- Webhook trigger integration

Planned for future milestone. See [docs/integrations/](../../docs/integrations/) for integration guides.
