# Home Assistant Integration

Home Assistant integration for the Nexloza IoT platform.

## Purpose

This directory will contain the custom Home Assistant component that allows Nexloza devices to appear as native Home Assistant entities (sensors, switches, lights, covers).

## Planned Features

- MQTT-based auto-discovery of Nexloza devices
- Bidirectional state synchronization
- Support for sensors, actuators, and automation triggers

Planned for future milestone. See [docs/integrations/](../../docs/integrations/) for integration guides.
