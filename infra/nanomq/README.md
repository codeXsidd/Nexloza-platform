# NanoMQ — NEXLOZA MQTT Broker

NanoMQ is NEXLOZA's primary open-source MQTT broker.

- **License:** MIT
- **MQTT:** 5.0 + 3.1.1 compatibility
- **Image:** `emqx/nanomq:0.22.6-slim`
- **Source:** https://github.com/nanomq/nanomq

## Local development

Use the [Windows IoT kit](../../docs/LOCAL_DEVELOPMENT_SETUP.md). It writes a local broker configuration with generated credentials and starts a loopback listener on 1883. The broker denies anonymous connections. The fixture device can publish only to its own telemetry topic and the bridge can subscribe only to that topic.

The root and standalone Compose files also accept a prepared broker configuration directory through `NEXLOZA_BROKER_CONFIG`. Without one they expect the ignored `.nexloza-iot` directory. Compose selects that mounted configuration explicitly. Use only one Compose project at a time on the same host port.

## Topic Structure

All NEXLOZA MQTT topics follow this canonical format:

```
nexloza/v1/{organization_id}/{project_id}/{device_id}/{channel}
```

### Channels

| Channel | Direction | QoS | Retained | Description |
|---------|-----------|-----|----------|-------------|
| `telemetry` | Device → Cloud | 0 | No | Sensor readings |
| `command` | Cloud → Device | 1 | No | Device commands |
| `command-ack` | Device → Cloud | 1 | No | Command acknowledgements |
| `state` | Device → Cloud | 1 | Yes | Actuator state reports |
| `status` | Device → Cloud | 1 | Yes | Online/offline status |
| `config` | Cloud → Device | 1 | Yes | Device configuration |

## ACL rules

Use NanoMQ HOCON `rules` entries with explicit topic, role, and action. Deny unmatched operations. The disposable broker configuration is generated by [the runtime kit](../../scripts/iot/runtime.py). The checked-in files in `config/` are historical reference files and are not loaded by the development Compose services.

## TLS (Production)

For production deployments, uncomment the TLS listener in `nanomq.conf` and provide:
- `server.key` — Server private key
- `server.crt` — Server certificate
- `ca.crt` — CA certificate
