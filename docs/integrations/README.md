# Integration Guides

Documentation for connecting Nexloza with third-party platforms and services.

## Supported Integration Types

- **Alexa** -- Voice control via Alexa Smart Home skill
- **Google Home** -- Voice control via Google Home Actions
- **Webhooks** -- HTTP callbacks for external event processing
- **MQTT Bridge** -- Bridge to external MQTT brokers
- **Custom** -- Developer-defined integrations
