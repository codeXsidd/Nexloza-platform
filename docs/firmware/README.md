# Firmware Documentation

Guides for developing and deploying firmware on IoT devices that connect to the Nexloza platform.

## Supported Hardware

- ESP32 (primary target)
- ESP8266
- Raspberry Pi
- Generic MQTT-capable devices

## Planned Contents

- Firmware SDK quickstart (Arduino / PlatformIO)
- Device provisioning and credential setup
- MQTT connection and telemetry publishing guide
- OTA firmware update workflow
- Hardware wiring diagrams and example projects

Planned for future milestone. See [MQTT Protocol](../api/mqtt-protocol.md) for the communication protocol that devices implement.
