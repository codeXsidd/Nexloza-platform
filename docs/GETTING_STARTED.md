# Getting Started

> Quick-start guide for NexIoza developers.

## Prerequisites

- Flutter 3.47+ (stable channel)
- Dart 3.13+
- Android SDK 34+
- Git
- Node.js 18+ (for device simulator and Supabase CLI)
- Docker (for local Supabase and MQTT broker)

## Quick Start

```bash
git clone https://github.com/your-org/nexioza-platform.git
cd nexioza-platform/app
flutter pub get
flutter run
```
